# Image provenance

The gallery contains genuine app captures and the existing logo. Files are byte-for-byte copies of their originals; no screen was generated or retouched.

- `peel-logo.png`: the application logo in `Peel/Assets.xcassets/PeelLogo.imageset/`.
- `review.png`, `unfollowers.png`, `followers.png`, `mutual.png`, `menu.png`, `ipad.png`: the supplied screenshots. Original copies remain locally in the ignored `Screenshots/` directory.
- The three account-list images show fictional `peeldemo_*` usernames. The dashboard shows aggregate counts without an account identifier; its dataset provenance is not independently established. The menu includes the application's public author attribution.
- Captures predate the latest automated results. The iPad's dimmed informational card predates an accessibility correction, and the menu predates current information entries. They illustrate the interface, not current visual-regression coverage.

PNG chunk inspection found no EXIF or text/XMP metadata; some files contain an ICC color profile. No credentials, authenticated browser content or private usernames were visible. Image and service-branding rights remain a separate consideration.
